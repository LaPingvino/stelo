# Stelo

*Stelo* ("star") is a platform game in Esperanto by LaPingvino, made with Game Maker 5.3 in 2006 and put on
[itch.io](https://lapingvino.itch.io/) in 2018. Climb the ladders, collect the stars, jump on the monsters, and
find the way out of five levels and a bonus level.

The game's source was lost long ago. [`original/`](original/) is that source, read back out of the game itself
with [gm53-reader](https://github.com/LaPingvino/gm53-reader): every object's code, the levels, the sprites,
the sounds and the music, as they were in 2006.

A remake in Go with Ebitengine, playable in the browser and with a level editor, is planned here.
